# Демонстрационные данные

initial-data.json — исходная заготовка вымышленных данных.
Формат предварительный и будет согласован со схемой БД.

## Состав

- 1 наставник.
- 5 пользователей.
- Группа «ИС-21».
- Групповое задание на 4 успешные Focus-сессии.
- История сессий изначально пустая.

## Правила использования

- ID служат для связи записей внутри набора.
- Пароли и реальные персональные данные отсутствуют.
- Email используются как тестовые значения, отправка писем не требуется.
- deadlineOffsetDays = 7 означает дедлайн через 7 суток
  после загрузки набора. Будущий загрузчик преобразует
  это значение в конкретную дату и время UTC.
- Исходный прогресс каждого участника — 0/4.
- Прогресс и статусы должны рассчитываться приложением.
- Для короткой демонстрации длительность сессии можно
  установить в 1 минуту через настройки приложения.

Загрузчик БД и история для проверки разных статусов
будут подготовлены в рамках пакета ИСР 4.3.
