# Pomodoro Focus

Учебный проект по дисциплине «Управление проектами».

Веб-приложение для концентрации по методу Pomodoro.
Две роли: Пользователь и Наставник. Пользователь работает
с личными задачами и таймером, наставник управляет группами,
назначает задания и организует групповые Focus-сессии.

## Текущий этап

Подготовка окружения перед первой итерацией.
Функциональность приложения пока не реализована.

## Предварительный стек

- Клиент: React + TypeScript + Vite.
- Анимации: SVG + CSS/JavaScript.
- Сервер: Node.js, NestJS и Socket.IO.
- База данных: PostgreSQL.
- Развёртывание: Docker Compose и Nginx на VPS.

Стек предварительный. Окончательно фиксируется
разработчиком в первом спринте.

## Структура репозитория

- frontend/ — клиентская часть.
- backend/ — серверная часть.
- infra/ — конфигурация окружения и развёртывания.
- demo/ — вымышленные демонстрационные данные.
- docs/ — технические инструкции.

## Среда разработки

На компьютере, использованном для первичной настройки:

- Node.js 24.21.0.
- npm 11.19.0.
- Git 2.50.1.
- Docker 29.2.0.
- Docker Compose 5.0.2.
- macOS, Apple Silicon ARM64.

Версия Node.js записана в .nvmrc.
Перечень выше фиксирует проверенную среду одного участника.
